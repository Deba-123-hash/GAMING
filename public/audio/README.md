# Audio Directory (`public/audio/`)

Store stadium ambience, crowd swells, ball strikes, and subtle UI feedback audio sprites for Howler.js.

- **Accepted Formats:** `.ogg`, `.mp3`, `.webm`
- **Example Filename:** `stadium-ambience-loop.ogg`, `ui-tab-click.mp3`
- **UX Rule:** Never autoplay audio on page load. Audio triggers only after user opt-in via the navbar audio control.
