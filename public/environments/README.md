# Environments & HDRIs (`public/environments/`)

Store equirectangular environment maps for physically based stadium floodlight reflections and IBL (Image-Based Lighting).

- **Accepted Formats:** `.hdr`, `.exr` (prefer low-res `512px–1K` `.hdr` for reflection probes to keep memory low)
- **Example Filename:** `stadium-night-floodlights-1k.hdr`
- **Licensing:** Verified CC0 HDRIs (e.g., Poly Haven) logged in `docs/3D_ASSET_LICENSE_REGISTER.md`.
