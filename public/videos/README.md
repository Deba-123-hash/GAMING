# Videos Directory (`public/videos/`)

Store compressed background loops and fallback reels for non-WebGL / low-power devices.

- **Accepted Formats:** `.mp4` (H.264/H.265), `.webm` (VP9/AV1)
- **Example Filename:** `hero-stadium-loop-720p.webm`
- **Performance Rule:** Keep background loops muted, short (`< 12s`), and compressed under `4 MB`.
