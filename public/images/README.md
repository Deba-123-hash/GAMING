# Images Directory (`public/images/`)

Store 2D web imagery, posters, player portraits, team crests, and WebGL fallback banners.

- **Accepted Formats:** `.avif`, `.webp`, `.png`, `.svg`
- **Example Filename:** `stadium-hero-fallback.webp`, `team-apex-united-crest.svg`
- **Originality Rule:** All crests, kits, and character portraits must be original RIVALRY 90 artwork.
