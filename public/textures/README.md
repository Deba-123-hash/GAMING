# Textures & Materials Directory (`public/textures/`)

Store PBR surface maps (Albedo, Normal, Roughness, Metalness, AO) used by stadium, pitch, kit, and player materials.

- **Accepted Formats:** `.ktx2` (Basis Universal), `.webp`, `.avif` (avoid uncompressed `.png`/`.tga` in production)
- **Resolution Budgets:** Desktop max `2048x2048` (hero), Mobile max `1024x1024`
- **Example Filename:** `pitch-turf-albedo-1k.webp`, `kit-apex-home-normal.ktx2`
- **Licensing:** Original textures or verified CC0 PBR sets (e.g., Poly Haven) logged in `docs/3D_ASSET_LICENSE_REGISTER.md`.
