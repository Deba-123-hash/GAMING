# Fonts, Icons & Placeholders (`public/fonts/`, `public/icons/`, `public/placeholders/`)

- `public/fonts/`: Self-hosted custom display fonts (`.woff2`) if used alongside `next/font/google`.
- `public/icons/`: PWA / favicon / brand SVG icons.
- `public/placeholders/`: Lightweight low-res blur or fallback posters used when 3D assets are loading or WebGL is disabled.
