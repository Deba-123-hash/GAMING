# 3D Animations Directory (`public/animations/`)

Store skeletal animation clips (embedded inside `.glb` or standalone animation `.glb` tracks) compatible with the humanoid athlete armature.

- **Subfolders:** `players/{idle,walking,running,dribbling,shooting,celebration}`, `crowd/`, `stadium/`
- **Accepted Formats:** `.glb`, `.gltf` (exported via Blender NLA tracks from Mixamo or Cascadeur)
- **Example Filename:** `player-shooting-volley-v1.glb`
- **Licensing:** Verify commercial redistribution terms for any third-party motion capture data.
