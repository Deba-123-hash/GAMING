- Enable RLS on tables exposed through Supabase APIs.
- Review SELECT policies.
- Review INSERT policies.
- Review UPDATE policies.
- Review DELETE policies.
- Verify user ownership.
- Verify role-based access.
- Prevent unauthorized access through direct API calls.
- Protect service-role credentials.

If using Neon or standard PostgreSQL:

- Enforce server-side authorization.
- Use restricted database roles.
- Keep database access server-side.
- Protect administrative operations.
- Prevent unauthorized data access through application APIs.

Do not assume one provider's security model applies to another.

Test authorization at the API and database layers where applicable.
