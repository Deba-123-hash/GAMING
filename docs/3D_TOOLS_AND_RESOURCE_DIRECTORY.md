# 3D Tools & Resource Directory

Central reference accompanying `/resources/3d` (`src/data/threeDResources.js`).

## A. Core npm 3D & Animation Packages (Installed in Project)
| Package | Purpose | Docs |
|---|---|---|
| `three` | WebGL 3D engine | https://threejs.org/docs/ |
| `@react-three/fiber` | React renderer for Three.js | https://r3f.docs.pmnd.rs/ |
| `@react-three/drei` | Helpers, loaders, controls, environment | https://drei.docs.pmnd.rs/ |
| `@react-three/postprocessing` | Bloom, vignette, tone-mapping effects | https://react-postprocessing.docs.pmnd.rs/ |
| `@react-three/rapier` | Physics engine wrapper (future interactive props) | https://github.com/pmndrs/react-three-rapier |
| `gsap` & `@gsap/react` | ScrollTrigger & timeline orchestration | https://gsap.com/docs/v3/ |
| `motion` | React UI interactions & transitions | https://motion.dev/docs |
| `leva` (devDependency) | Dev-only 3D parameter GUI | https://github.com/pmndrs/leva |
| `@gltf-transform/cli` / `gltf-validator` / `gltfjsx` | GLB optimization, validation, JSX generation | https://gltf-transform.dev/ |

## B. 3D Modelling & Creation Software (External Desktop / Browser)
- **Blender** (Essential, Free/Open Source): https://www.blender.org/
- **Spline** (Recommended, Freemium Browser/Desktop): https://spline.design/
- **Autodesk Maya** (Optional/Advanced, Paid): https://www.autodesk.com/products/maya/overview
- **ZBrush** (Optional/Advanced, Paid): https://www.maxon.net/en/zbrush

## C. Character Rigging, Animation & Texturing
- **Mixamo** (High Priority, Free with Adobe Account): https://www.mixamo.com/
- **Cascadeur** (Recommended, Freemium): https://cascadeur.com/
- **Adobe Substance 3D** (Optional/Advanced, Paid): https://www.adobe.com/products/substance3d.html
- **Meshy** (Optional AI Concepting, Freemium): https://www.meshy.ai/
