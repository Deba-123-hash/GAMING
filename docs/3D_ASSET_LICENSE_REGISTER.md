## Mandatory IP & Licensing Policy

1. **Original Fictional Universe Only:** Never download or ship real professional football players' likenesses, trademarked club crests, licensed league kits, or copyrighted championship trophies.
2. **Verify Every File Individually:**
   - **Poly Haven:** Published under **CC0 1.0 Universal** (commercial use permitted, attribution optional). Still log asset URL and download date below.
   - **Kenney Assets:** Published under **CC0 1.0 Universal**. Retain license file.
   - **OpenGameArt:** Licenses vary (`CC0`, `CC BY 3.0/4.0`, `CC BY-SA`, `GPL`). Avoid `NC` (Non-Commercial) or `ND` (No-Derivatives) assets.
   - **Sketchfab / Fab / CGTrader:** Check each listing's exact license (`Standard`, `CC BY`, `Editorial`). **Never** use `Editorial` or `CC BY-NC` assets in commercial RIVALRY 90 branding. Never redistribute raw marketplace source packages.
   - **Meshy AI:** Verify current paid/free plan commercial ownership terms before using generated models in production.
