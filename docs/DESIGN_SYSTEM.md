# Design System Reference (Phase 06)

Inspect interactive component variants live at **`/design-system`** (`src/app/design-system/page.jsx`).

## Core Tokens (`src/styles/tokens.css`)
- **Dark Theme (Primary):** `#080B09` background, `#101713` secondary, `#151D18` card, `#C6FF3D` electric lime, `#FF6B35` football orange, `#F5F7F2` primary text, `#9BA69D` secondary text, `#29342D` border.
- **Light Theme Tokens:** Defined under `[data-theme="light"]` in `tokens.css` for future theme toggle readiness while keeping the dark stadium aesthetic as the flagship default.
- **Standardized Primitives (`src/components/ui/`):** `Button`, `IconButton`, `Card`, `Badge`, `Input`, `Textarea`, `Select`, `Tabs`, `Accordion`, `Modal`, `Skeleton`, `EmptyState`, `Divider`.
